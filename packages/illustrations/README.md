**Important** : le travail est authentiquement vectoriel, sans image embarquée, et la réutilisation amont est détaillée dans `THIRD_PARTY_NOTICES.md`. La validation automatique du backlog global reste distincte et n'atteste pas que ces illustrations ont été approuvées.
