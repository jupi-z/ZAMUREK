# Zamurek — uniquement les originaux SVG IRA Design et Humaaans

**Aucune géométrie SVG nouvelle. Aucun objet SVG inventé. Aucune animation ajoutée.**

Le traitement couvre **257 cas ZIL-001 à ZIL-257**, sur les 275 du registre historique. Les cas ZIL-258 à ZIL-275 sont volontairement exclus.

Les 62 illustrations sources (30 scènes originales IRA Design Gallery + 32 personnages Humaaans) sont copiées dans sources/original.

Les 514 fichiers thématiques (clair/sombre par cas) sont des copies réutilisées avec uniquement des substitutions hexadécimales de couleurs. Les 124 variantes de la bibliothèque de sources sont accessibles sous assets/themes.

Le fichier HTML ZAMUREK_VISUALISATION_SOURCES_257.html est autonome et incorpore les 124 SVG de sources. Les 257 cas réutilisent ces sources, donc ne représentent pas 257 dessins indépendants.

Chaque lien vers les originaux et SHA-256 se trouve dans registry/257-source-mapping.json et registry/upstream-sources.json.

IMPORTANT : le choix des illustrations par cas est une association générique à revoir. Aucune correspondance métier précise n'est affirmée. Les thèmes conservent les formes exactes des SVG tiers.
