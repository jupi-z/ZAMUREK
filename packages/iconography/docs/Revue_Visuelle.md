# Revue visuelle

Les 288 dessins couleur et 288 rendus interface ont été rendus en PNG pour contrôle interne. Les dix planches de revue ont été examinées, puis les planches affectées par les corrections ont été revues. Les planches internes ne sont pas des images incorporées aux SVG.

Corrections apportées : croix explicite pour accès refusé ; position inversée pour l’interrupteur désactivé ; dégagement vectoriel derrière les badges d’interface ; arête vert grisé pour les pièces ivoire sur fond blanc ; recoloration des traits pleins en plus des dégradés dans le catalogue ; libellés adaptés aux usages lorsque le même pictogramme est réutilisé.

Le contrôle de rendu a vérifié 576 fichiers, leur présence à 24 px et l’absence de dépassement du cadre selon les bornes alpha documentées dans le rapport. Les objets riches et leurs badges bénéficient d’une taille supérieure, indiquée dans le guide.

Le catalogue a été examiné sur ordinateur et mobile ; recherche accentuée et par capacité, catégories, rendu monochrome, fonds, taille, palette, vue détaillée, SVG et export ZIP ont été exercés. Les contrôles automatiques ne remplacent pas un test utilisateur de compréhension.
