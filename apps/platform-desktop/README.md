# xShop Platform Admin Desktop — G0

**Administration centrale Windows installable, EXE/MSI, non implémentée.** React UI empaquetée + Tauri 2/Rust Core, jamais portail web hébergé.

Rôles plateforme et authentification renforcée, provisioning tenant, canal/distribution, statuts, migrations, audit, supervision et vérification de deux bases isolées. Aucun accès spontané aux commandes personnelles des marchands.

Voir [tenancy](../../docs/architecture/TENANCY.md), [déploiement](../../docs/architecture/CLIENTS-DEPLOYMENT.md).
